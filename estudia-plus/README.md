# Estudia+ (PWA)

Aplicación Web Progresiva para organizar tareas y estudiar con Pomodoro.
Funciona sin conexión, es instalable, usa notificaciones y muestra insignia (badge) con las tareas pendientes.

## Publicar en GitHub Pages
1. Crea un repositorio (ej. `estudia-plus`) y sube todos los archivos de esta carpeta a la raíz.
2. En GitHub: Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
3. Tu URL será `https://TU-USUARIO.github.io/estudia-plus/` (HTTPS incluido).

## Probar local
`python3 -m http.server 8000` y abre http://localhost:8000
